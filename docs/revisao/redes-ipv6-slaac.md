24 bits = ff02::1:ff9c:4b15; MAC multicast = 33:33 + últimos 32 bits = 33:33:ff:9c:4b:15.
RA: prefixo 2001:db8:20::/64, válido 86400 s, preferido 43200 s, A=1. Global = prefixo + IID.
Gateway fe80::1 (quiz); NS para ff02::1:ff00:1. Checksums ICMPv6 com pseudocabeçalho conferidos.
