# redes/ping-traceroute

Atrasos de ida por salto (ms): 1, 6, 9, 4. Acumulados: 1, 7, 16, 20 → RTT 2, 14, 32, 40.
TTL na resposta do ping: 64 − 3 roteadores = 61. A sonda que chega ao destino precisa de TTL 4
(resposta do quiz). Erros ICMP 11 e 3/3 carregam o cabeçalho IP original + 8 bytes (RFC 792).
Checksums IPv4, ICMP e UDP de todos os quadros conferidos no teste.

Para o dono conferir:

- [x] capítulo e seção do Tanenbaum e os RFCs citados em `refs`;
- [x] a lição inteira em `npm run dev`, com e sem o Laboratório.
