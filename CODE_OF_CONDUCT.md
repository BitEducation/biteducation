# Código de conduta

Este projeto é um espaço de aprendizado. Esperamos de todas as pessoas que participam
(issues, PRs, discussões e revisões):

- respeito e paciência, principalmente com quem está começando;
- críticas dirigidas ao conteúdo e ao código, nunca à pessoa;
- linguagem acolhedora, sem assédio, ofensas, insinuações sexuais ou discriminação de
  qualquer tipo;
- nada de expor dados pessoais de outras pessoas.

Comportamentos fora disso podem levar à remoção de comentários, ao bloqueio temporário ou ao
banimento do projeto, a critério dos mantenedores.

Para relatar um problema de conduta sem expor ninguém, use o recurso de denúncia do GitHub
("Report content") no comentário ou no perfil, ou abra um aviso privado pela aba
**Security → Report a vulnerability** indicando que se trata de conduta.

Este texto se baseia nos princípios do Contributor Covenant, versão 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
